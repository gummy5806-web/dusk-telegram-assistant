# Разбор личных мыслей

Пользователь подтвердил 10 октября 2026: по обычному запросу разобрать записанные
мысли, вернуть намерения, связи, следующий шаг, вопросы и предложение отложить.
У каждого вывода — исходные записи. Никаких автоматических задач/переносов.

## Поток

«💡 Разбор мыслей» в меню, хабе мыслей и через меню после «📊 Статус» открывает
сегодня/вчера/неделя/последние. Работают обычные фразы, включая
«разбери мои мысли за вчера» и «что я вчера записывал». В режиме записи мысли
эти же слова являются содержанием, а не управлением.

Бот VPS создаёт неизменяемый запрос с ID и временем. Штатный Git переносит
его на Mac. Новый LaunchAgent каждые 60 секунд обрабатывает очередь через
существующий Vertex. Результат синхронизируется обратно и доставляется ботом.
Mac sleep не превращается в выдуманную синхронную сводку: ожидание объясняется.
Период считается по времени запроса в Asia/Almaty, даже если обработка позже.

## Данные и доказательства

Только публичный Inbox и FLEETING_DAILY; ограниченный контекст текущих задач.
Private и Research Brain исключены, symlink-пути отвергаются до чтения.
Полный смысловой текст ограничивается по размеру; срез явно помечается.
Старые строки Inbox без календарного дня — контекст с неизвестной датой.

Модель получает источники с локальными ID и не выполняет инструкции из записей.
JSON проходит проверку схемы, размеров и ссылок: каждый пункт обязан указывать
на существующие источники. Ошибка модели/схемы даёт ошибку разбора, а не
сгенерированные без модели советы. Интерпретации — предложения, не установленный
приоритет владельца. Источники открываются exact identity существующим thought UI.
Из исходной мысли владелец сам создаёт задачу либо скрывает её на 7 дней.

## Надёжность

Immutable requests/results, атомарная запись, ограниченная очередь, общий local
worker lock. Git staging только явных файлов очереди, нейтральные messages,
повторная попытка после sync failure. Локальная delivery DB сохраняет подтверждённые
отправки через перезапуск VPS. Crash после Telegram send до acknowledgement может
повторить уведомление; exactly-once между Git и Telegram не заявляется.

Секреты и credentials не копируются на VPS. Личная генерация всегда явно
`provider='vertex'` на Mac; сторонний endpoint не используется как fallback.

## Приёмка

RED/GREEN tests core/queue/PTB/delivery; полный suite на локальной копии и
целевом VPS; read-only ревью; SHA-256 whitelist и сохранность пользовательских
файлов; backup перед интеграцией. Реальный запрос через разрешённый Vertex на Mac
проверяется отдельно от mocks и его результат возвращается владельцу в Telegram.
