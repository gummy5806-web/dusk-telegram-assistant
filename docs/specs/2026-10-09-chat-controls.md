# Dusk: управление прямо в чате

Запрос владельца: основные кнопки в сообщениях, доступное напоминание с колокольчиком,
правка/удаление мусора после голосовой расшифровки, подробный отчёт результата.

## Контракт

Главное меню — InlineKeyboardMarkup в сообщении. Старую ReplyKeyboard удалить
при первом новом взаимодействии. /menu и слово «меню» возвращают меню; старые
текстовые кнопки остаются совместимыми. Кнопки: мысль, мысли, новая задача,
задачи, напомнить, статус, материал. Экранные переходы используют короткие callback
без текста/путей. Авторизация обязательна и для callback.

Созданная задача сразу получает карточку с фокусом и напоминанием.
«🔔 Напомнить» в главном меню даёт новое напоминание обычными словами либо выбор
существующей задачи с переходом сразу к времени. Ошибочное время не идёт в Inbox.
Нотификации напоминания и конца фокуса отправляются с disable_notification=False;
звук остаётся зависимым от настроек Telegram/телефона. Телефонный звонок не обещается.

После сохранения обычного текста/голоса точная запись получает inline-действия.
✏️ Исправить заменяет содержание той же записи, не создаёт дубль. 🗑 Удалить
просит подтверждение, переносит восстанавливаемую копию в .trash и удаляет только
выбранную запись. ↩️ Восстановить не перезаписывает появившийся файл/соседние мысли.
Устаревшая карточка отказывает в мутации. Private, Research Brain, задачи и соседние
секции Inbox не меняются. Все git messages нейтральны; содержимое не логируется.

Реализация ограничена Bot API; это работающий интерфейс внутри чата, а не отдельно
опубликованное веб-приложение. Бизнес-логика/TaskNotes/таймеры сохраняются.

## Проверка

Исполняемые тесты реальной PTB 21.5 markup и callback, text/voice общего маршрута,
исправления и удаления с повтором/stale/соседними записями, отказа чужому пользователю,
ошибочного времени и звукового delivery; полный существующий suite; compile/diff.
Интеграция только whitelisted code files поверх новых пользовательских данных,
backup до deploy, проверка версии/службы после restart, один настоящий menu message
в личном чате владельца. Канбан/Caps+N и секреты сохраняются.
